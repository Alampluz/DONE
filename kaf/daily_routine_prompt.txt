KNOWN LAZADA BEHAVIOUR (learned 23 Nov 2026):
- Place of Origin (country_origin_hb) in makeup brush / tool categories (4125, 4126, 4127) is accepted by the API ("updated") but NEVER stored. Do not write it there; mark the row "Blocked - Lazada API does not save Place of Origin for brush/tool categories" with the value in known, for Seller Center entry.
- Numeric measure attributes (capacity, volume, Net_Content in ml/g, weight, length, Width, Height) fail with BIZ_CHECK_MEASURE_UNIT_INVALID / UNIT_IS_EMPTY because the tool sends no unit: status "Manual - Seller Center".
- color_family on single-variant jewellery fails with BIZ_CHECK_TOTAL_SALE_PROP_MAX_ITEMS: status "Manual - Seller Center".
- Before applying, check the preview's "current" value: never overwrite a non-empty current value (drop that attribute from the change).
- Listing descriptions (get_product, HTML stripped) are a valid source for shelf life, net content, composition (e.g. "100% Wool"), SPF, embroidered logo, swimwear etc. Cite "Lazada description" as source.

- APPROVED LEAST-WRONG VALUES (niramol.k, 23 Nov 2026) for Lazada template gaps where no option can be true: Men's Jeans (category 7071) Shorts Length = "BERMUDA"; Women's Blouses & Shirts (6687) Blouse Style = "Shirred Blouse"; fashion caps in Sports Hats & Caps (12410) Activity Type = "Walking". Write these automatically for new listings and log source "least-wrong option, approved 23 Nov". Listings clearly in the wrong category (caps/skirts asked for Neckline, casual shoes asked for Formal Shoes Type, blankets asked for Heat Duration): status "Need Lazada", do not write.
- Photo judgement is allowed for jackets_closure_type (Zipper / Single Breasted / Double Breasted / Pullover) and Bag_Feature_Design (Top Handle / Adjustable Strap where allowed) when the first product image shows it plainly; source "product photo".
- If Lazada answers CHK_CATPROP_CPV_REQUIRED naming other empty mandatory fields, add those fields to the same change when their value is plain (Fit_Type from title, Neckline from garment type) and retry once.
- backpack_capacity / Load_Capacity / color_family are variant-level on single-variant listings and fail with BIZ_CHECK_TOTAL_SALE_PROP_MAX_ITEMS: status "Manual - Seller Center".
